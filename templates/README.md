# Wzór: rolka testowa (28,5 s)

`reel.html` to pełna rolka z testu skilla: obiektyw → taśma klatek → zegar → dłoń i oś czasu → klepsydra → kula z inspiracjami → mózg z cząsteczek → ekran rolki. Służy jako wzór budowy scen, kamery, napisów i zdarzeń do dźwięku.

Żeby ją uruchomić, skopiuj ją do `work/<nazwa>/` i dołóż obok:
- `ready/vo.wav`, `ready/words.json`, `ready/timing.json` (z `tools/prep_audio.py`),
- `assets/models/hand.glb` i `assets/models/brain.glb` (dowolne modele dłoni i mózgu w GLB),
- opcjonalnie `assets/insp/1.png` … `8.png` (inspiracje krążące wokół kuli).

Kolory: `?preset=granat` (domyślny), `?preset=czerwien`, `?preset=zloto` albo własny plik w `presets/`.
